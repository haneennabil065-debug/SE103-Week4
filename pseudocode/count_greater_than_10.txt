Problem:
Count how many numbers in a list are greater than 10.

Input:
a list of numbers

Output:
the count, or an error if the list is empty

Pseudocode:
START
IF the list is empty THEN
Display "Error: list is empty"
ELSE
Set count = 0
FOR each number in the list
IF number > 10 THEN
Increase count by 1
END IF
END FOR
Display count
END IF
END
